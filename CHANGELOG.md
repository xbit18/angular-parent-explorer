# Changelog

## 0.1.0 — Private preview

- Navigate direct standalone Angular component consumers and template occurrences.
- Pin and filter the native parent tree; expand, collapse and rebuild from view actions.
- Analyze in a worker with a local disk cache and provisional startup results.
- Report progressive diagnostics, startup timings and sampled memory usage.

This package is for local evaluation, not a verified Angular-version compatibility release.
